# bevy-manual-mcp — name reservation

This crate name is reserved for the native (Rust) rewrite of
[bevy-mcp](https://github.com/kinkirill/bevy_manual_mcp).

The MCP server is **not published yet**. This 0.0.1 release is a library-only
placeholder: `cargo install bevy-manual-mcp` will fail with "no binaries" until
the first real release, which will install the `bevy-mcp` command.
